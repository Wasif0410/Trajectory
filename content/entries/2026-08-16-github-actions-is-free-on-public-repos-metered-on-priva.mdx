category: professional
tags: [github-actions, ci]

Spent today figuring out how GitHub Actions actually works, mostly because I wanted a personal log of my work and built a front end app for it.

The bit that stuck: it's free to use on public repos. Private repos get a capped allowance instead, so the same workflow that costs nothing on a public project is metered on a private one.

Good thing to know before wiring up anything that runs on a schedule.
